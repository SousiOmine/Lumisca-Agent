# Web スタイル構成

`../styles.css` をエントリーポイントとし、実際のスタイルは本ディレクトリの個別ファイル群で管理しています。MDN の「CSS の整理」の指針に沿った構成です。

- 単一の大きなスタイルシートではなく、全体共通ルールと各画面・コンポーネントごとのシートに分割しています。
- カスケードの優先順位は、`styles.css` における `@import` の記述順に従います。

## ファイル一覧（読み込み順）

| 順 | ファイル | 内容 |
|---|---|---|
| 1 | `tokens.css` | Fluent デザイントークン（ダーク／ライトのテーマ変数） |
| 2 | `base.css` | ベース要素、ボタン、スクロールバーなどの共通スタイル |
| 3 | `motion.css` | アニメーション用の共通 keyframes |
| 4 | `layout.css` | 全体レイアウトとドッキングペイン |
| 5 | `chrome.css` | タイトルバー、タブバー、メニュー、稼働状態表示 |
| 6 | `chat.css` | チャット画面、メッセージ、ツール実行ログ |
| 7 | `side-panels.css` | 進捗パネル、質問カード |
| 8 | `composer.css` | 入力欄、添付ファイル、スラッシュメニュー |
| 9 | `pickers.css` | 新規セッション、履歴、ピア／ワークスペース選択 |
| 10 | `model-picker.css` | モデル切り替え、思考レベル設定、コンテキスト表示 |
| 11 | `modals.css` | モーダルウィンドウ、エラーバナー |
| 12 | `settings.css` | 設定画面と各設定パネル |
| 13 | `banners.css` | アップデート通知、サーバー停止通知バナー |
| 14 | `folder-browser.css` | ワークスペースのフォルダー選択 UI（2ペイン表示） |
| 15 | `reduced-motion.css` | `prefers-reduced-motion` 用のアニメーション無効化 |

## スタイル追加の手順

1. スタイルを記述するファイルは上記の一覧から選びます。
2. 既存の分類に収まらない場合にのみ新規ファイルを作成し、カスケード順を考慮して `../styles.css` の `@import` に追加してください。
3. アニメーションは `opacity` または `transform` のみを使用し、時間は 120〜180ms、イージングは `var(--lum-ease)` を指定します。また、`reduced-motion.css` への無効化設定を必ず追加してください。

## レスポンシブ設計

画面幅の条件は 3 つ、入力デバイス（タッチ）の条件は 1 つです。これらは `tokens.css` の先頭で定義されており、`styles_test.ts` で検証されます。

| 条件 | 分類 | 適用内容 |
|---|---|---|
| `@media (max-width: 900px)` | compact | 余白の削減、折り返しの許可、固定幅の解除 |
| `@media (max-width: 720px)` | pane | ドッキングペインが本文を覆う幅（`layout.css` でのみ使用） |
| `@media (max-width: 600px)` | phone | 1 カラム表示、全画面モーダル、上部に配置する進捗パネル |
| `@media (hover: none), (pointer: coarse)` | touch | ホバー前提の操作の常時表示、タップ領域の拡大、入力欄を 16px 以上に設定 |

- **メディアクエリの記述位置**: 上書きルールは該当コンポーネントのシート末尾に記述します。シート単位でカスケードされるため、同じシート内の通常ルールより優先されます。他のシートのルールを別シートから上書きすることは避けてください。
- **高さの指定**: `vh` はブラウザの UI やソフトウェアキーボードの変化に対応できないため、画面に合わせる要素（モーダルやパネルなど）には `dvh` を使用します。アプリ全体の高さは `--app-height`（既定値 `100dvh`）とし、タッチ端末では `hooks/useAppHeight.ts` が `visualViewport` の高さを反映します。
- **動的な値の受け渡し**: キャレット位置（`--caret-x`, `--caret-y`）やダイアログの幅（`--modal-width`）など、場所に応じて動的に変わる値はインライン style で直接指定せず、CSS 変数として渡してください。

## ビルド時の留意事項

- 開発環境（Vite）では、Vite が `@import` を解決します。
- 本番・パッケージ版では、サーバー（`packages/server/assets.ts`）が `styles.css` の `@import` を同一順序でインライン展開して配信します。そのため、`styles/` ディレクトリ外への `@import` や URL 形式の参照は使用しないでください。
